桌宠大肥鱼 · 使用说明
========================================

一、启动
  双击「桌宠大肥鱼.exe」。
  只能开一个：已经开着的时候再双击，会弹「桌宠已经在运行」提醒
  （到托盘里找它就行）。两个同时跑会打架，所以挡掉了。
  AI 默认用 DeepSeek 云端（不用装任何东西）。第一次启动会自动弹出
  「AI 设置」窗口：把在 platform.deepseek.com 申请的 API Key 填进去，
  点「测试连接」看到成功后点「保存」即可。
  没填 Key 桌宠也会照常出现，但聊天前需要填一次。

二、AI 设置（随时可改）
  右键桌宠 →「AI 设置」，可以：
    · 填 / 换 API Key（只存在本机 config.json 里）
    · 换模型：deepseek-flash（快、便宜，推荐）或 deepseek-v4-pro（更强）
    · 开「思考模式」：回答更聪明，但要等几秒才开口
    · 选「回复长度」：简短（一句话） / 正常（约 200 字，默认） / 详细（不限）
    · 「测试连接」一键检查 Key 和网络
  还能切换后端：
    · DeepSeek 官方（默认）
    · OpenAI 兼容中转 / 其他服务（填对方的接口地址和模型名）
    · 本地 Ollama（不联网、免费，需要本机装 Ollama）

  回复长度也可以不进设置：右键桌宠 →「回复长度」直接切换。
  选「详细」时，人设里写死的「50 字以内」等限制会被自动覆盖。
  长回复在气泡里会自动翻页（右下角显示 1/2、2/2…），
  完整回复也随时存在桌宠目录的「最近一次回复.txt」里，
  右键 →「回复长度」→「查看最近一次完整回复」可以直接打开。

  气泡位置：默认在桌宠上方；上方放不下（比如贴着屏幕顶）就自动
  换到左右两侧，实在放不下才贴屏顶。桌宠被拖到哪儿，气泡都会
  跟着重摆，不会留在原地指向空气。

  气泡控制：
    · 鼠标移到气泡上会暂停自动收起（想看多久都行，移开才开始倒数）
    · 点击气泡任意位置立刻手动关掉（右上角有小 × 提示）
    · 显示时长整体比老版本长一倍

三、聊天
  双击桌宠（或右键 → 聊聊天）→ 输入框里打字 → 回车。
  回复显示在桌宠上方气泡里，长回复会自动翻页，看完自动收起。
  想要更长的回答：右键 →「回复长度」→ 详细，然后重新问一遍。
  右键 → 清空聊天记忆，可以重置对话。

  她在忙的时候（思考/干活/说话中），右键菜单第一项会出现
  「停！打断当前任务」：
    · 这是真打断：会通知 DSH 停掉正在跑的活，不只是桌宠闭嘴
    · 打断后想让她接着做，说一句「继续」就行
      （任务进度都在 DSH 的会话历史里，不会丢）
    · 空闲时点它，她会告诉你「现在没有正在做的事哦」

四、长期记忆（会记事）
  它现在不会「聊完就忘」了：
    · 每句话都会存进本文件夹的 memory.db（标准 SQLite 数据库）
    · 聊天记录太长时，旧的部分攒够几条后自动压成一段摘要
    · 你下次提问时，会先把相关旧事捞回来再回答

  右键 →「记忆（N 条）」：
    启用长期记忆     取消勾选就完全不存、不捞
    每次回忆几条     0（只存不用）/ 1 / 3（默认）/ 5
    立即整理记忆     手动把当前对话压成摘要
    查看 / 搜索记忆… 独立窗口：看摘要、翻最近条目、关键词搜索
    清空长期记忆…    二次确认后清空（只清当前人设的）

  几个细节：
    · 记忆按人设分开：切到「小蓝」看不到「大肥鱼」记住的事
    · 删掉 memory.db 就等于让它忘掉一切（想彻底重来就这么干）
    · 关掉记忆、库文件损坏、目录不可写时会自动降级成「没记忆」，
      聊天功能完全不受影响

五、跟 DSH 一起用（可选，推荐）

  桌宠可以不当「独立机器人」，而是接进 DSH 的会话：
  你在桌宠里说话 → 写进 DSH 的某一条会话 → 回复流式回到气泡。
  好处：记忆（DSH 插件市场那些记忆插件）、工具、历史记录全都用 DSH 的，
  你在 DSH 界面里也能看到这段对话。

  先分清「两条会话」，不然容易觉得她没反应：
    · 桌宠说话用的是她自己的那条会话（config.json 里的 dsh_session_id），
      不是你此刻在 DSH 界面里打开的那条；在 DSH 左侧会话列表里能看到它。
    · 两边上下文独立，互不串台。想让桌宠接着界面那条聊：
      右键 →「聊天模式」→「DSH 里换个会话…」，挑中那条即可。

  怎么开（只需做一次）：
    1. 关掉 DSH，再双击桌面「DeepSeek Harness」重新打开
       （插件在启动时加载，不重启不生效）
    2. 双击桌宠，右键 →「聊天模式」→ 选「DSH 会话」
    3. 右键 →「聊天模式」→「检查 DSH 连接…」
       看到「桥插件在线」就是通了

  用起来：
    · 直接双击桌宠说话，回复会流式出现在气泡里
    · 默认接着 DSH 里最近的那个会话聊
    · 想换会话：右键 →「聊天模式」→「DSH 里换个会话…」（也能新建）
    · 桌宠在执行工具时会显示「（正在用 xxx）」

  思考泡：
    · 跟桌宠说话：DSH 一进入思考，头上就冒「（💭 思考中…）」
    · 你在 DSH 界面里直接聊：她会自动跟到你正在用的那条会话
      （桥记的「最近活跃会话」一变，2~3 秒内跟过去），
      同样冒「（💭 想事情中…）」，正文一到就收掉
    · 同时开了多条会话时，只跟「最近有动静」的那条
    · （感知界面里的对话需要桥插件 0.1.1 以上，更新后重启一次 DSH）

  DSH 没开也不用手忙脚乱（自动拉起）：
    · 桌宠启动时会自己检查：桥没在线就悄悄帮你把 DSH 桌面版打开，
      等你说话时基本已经就绪
    · 聊天时如果 DSH 恰好没开，气泡会提示「正在帮你启动…」，
      启动好自动接着聊，不用你做任何事
    · 如果桌宠找不到 DSH 装在哪（少见），用记事本打开 config.json，
      在 "dsh_exe_path" 里填 DSH 的 DeepSeek Harness.exe 完整路径即可

  几个注意：
    · DSH 彻底打不开（自动拉起也失败）时，右键切回「独立 AI」照常聊天
    · DSH 模式下记忆归 DSH 管，桌宠自己的 memory.db 不再写入
    · 深度活（改一堆文件、跑很久的任务）还是去 DSH 界面做，
      气泡这块地方只适合短对话
    · 桥插件在 C://Users//<你>//.dsh//plugins//pet-bridge，
      想关掉就在 DSH 的 desktop profile 的 cordis.patch.yml 里删掉 pet-bridge 那段

六、放歌 / 播放
  1. 右键桌宠 →「打开 music 目录（往这里放歌）」，把
     mp3 / wav / flac / m4a / wma / aac 拖进去即可
     （ogg / opus 看系统有没有对应解码器，放不出来会直接提示）
  2. 放进去大约 1 秒后自动识别，不用重启也不用点扫描；
     右键 →「重新扫描 music/」是手动兜底
  3. 播放控制：
       播放音乐 / 暂停音乐
       下一首 / 上一首
       随机播放（可勾选）
       单曲循环（可勾选）
       选择曲目（直接指定某首）
  4. 播放时桌宠身边会飘音符，气泡显示歌名

  文件名开头的序号会自动去掉显示：
       01. 夏日限定.mp3  →  气泡显示「夏日限定」

七、换人设 / 换动作 / 换表情
  右键 →「切换人设」：
       大肥鱼   —— DeepSeek 胖鲸鱼（默认）
       小蓝     —— 蓝发女仆小精灵
  选择会被记住，下次启动还是这套。
  想改人设：切换人设 →「编辑当前人设…」，改完点「重载当前人设」。
  想加新人设：「新建人设…」，会生成一个模板文件。
  人设文件都在本文件夹的 personas 目录里，是纯文本，随便改。

  桌宠现在是 Live2D 模型「肥鱼」：自带呼吸、眨眼、头发物理。
  右键 →「播放动作」：呼吸待机 / 眨眼 / 点头 / 摇头
  右键 →「换表情」：微笑 / 悲伤 / 生气 / 惊讶

  （仅当 Live2D 无法启用时）右键 →「切换动作」：换序列帧待机动画
       站立待机 / 挥手 / 开心跳 / 害羞 / 惊讶 / 坐下休息 / 抱鲸鱼 / 背影
  同样会记住。聊天时角色还是当前动作，头顶会冒思考点或音符。
  想加新动作：往 assets\anim\ 下建个文件夹，放 00.png 01.png 02.png…
  （可选 meta.json 控制速度和播放顺序），重启后菜单里就有。
  想换回不会动的静态立绘：把 assets\anim 整个文件夹挪走即可。

八、其他
  左键拖动 = 移动位置（位置会记住）
  鼠标滚轮 / 右键 →「大小」= 调整桌宠大小（会记住）
  右键 → 退出（或托盘图标右键 → 退出）
  删除 config.json 可以重置所有设置（位置/音量/人设/AI 设置等）

九、目录说明（别删 _internal）
  桌宠大肥鱼.exe  主程序
  _internal\    运行库，删了程序就打不开
  personas\     人设文件，可编辑
  music\        放音乐的地方
  assets\       序列帧动画（anim\，Live2D 的备用形态），可替换
  _internal\live2d\   Live2D 模型文件（moc3/纹理/动作），别动
  最近一次回复.txt    AI 最近一次的完整回复（自动生成）
  config.json   自动生成的配置（含 AI 设置）
  memory.db     长期记忆库（自动生成，删掉就等于忘记一切）

  Live2D 没生效（变成静态立绘）  显卡需要支持 OpenGL 3.2+；
                                 不支持时会自动回退到序列帧动画，功能不受影响

十、常见问题
  桌宠不见了     删除 config.json 重启，会回到右下角
  放不出声音     确认 music 目录里有歌；放到歌会自动识别，
                 也可以右键点一次「重新扫描 music/」。
                 如果气泡提示「音频后端没起来」，说明系统解码器异常，
                 把 _trace.log 里 "music backend" 那一行发出来
  聊天报「API Key 无效」    右键 →「AI 设置」，重新粘贴 Key
  聊天报「余额不足」      去 platform.deepseek.com 充值，或换回本地 Ollama
  聊天没反应 / 转圈很久   检查网络；或在「AI 设置」里关掉思考模式
  想切回本地模型        右键 →「AI 设置」→ 服务商选「本地 Ollama」
  它忘了你说过的事      右键 →「记忆」→ 看「每次回忆几条」是不是 0；
                        再「查看 / 搜索记忆」确认到底存进去没有
  不想让它记住          右键 →「记忆」→ 取消「启用长期记忆」，
                        或「清空长期记忆」
  桌宠突然自己关了      右键 →「打开运行日志」。日志里最后一条没有配对的
                        "enter ..." 就是它当时在做什么，把 _trace.log
                        最后 20 行发出来就能定位（QQ 发我也行）
  桌宠卡住「未响应」    别急着点「关闭程序」！先等 3~4 秒，再用记事本打开
                        旁边的 _trace.log：如果出现「!!! 主线程疑似卡死」
                        加一大段代码行，把那几行发出来就能定位。
                        点「等待程序响应」它有时还能缓过来。
